# Contributing

Thanks for checking this project.

## Before you start

- This project is still early.
- Please keep changes small and clear.
- If you want to change the design, open an issue first.

## How to contribute

1. Fork the repo
2. Create a branch
3. Make your change
4. Test it if you can
5. Open a pull request

## Good first help

- Fix build issues
- Improve docs
- Improve logging
- Add safer worker auth
- Help with Jellyfin integration

## Style

- Use simple code
- Keep methods short
- Add comments only when needed
- Do not add big unrelated changes

## Pull requests

- Explain what changed
- Say how you tested it
- Add screenshots only if UI changed

Thanks for helping.
